# Vishu's Digital Diary ♡

A romantic, mobile-friendly digital diary website built with plain HTML, CSS and JavaScript.

## Folder structure

vishu-diary/
├── index.html
├── style.css
├── script.js
├── photos/
└── music/
    └── our_song.mp3

## Add your photos

Rename your photos exactly like this and put them inside `photos/`:

1. first_pink_kurta.jpg
   - Her in the pink kurta / the first-memory photo.

2. early_days.jpg
   - Early college / early-days memory.

3. notes_start.jpg
   - Notes, assignments, studying or classroom-related photo.

4. momos_promise.jpg
   - Momos / food memory.

5. birthday.jpg
   - Birthday celebration memory.

6. beach_1.jpg
   - First beach memory.

7. beach_2.jpg
   - Second beach memory.

8. churchgate.jpg
   - Churchgate / walking memory.

9. art_fest.jpg
   - Art Fest photo.

10. college_fest.jpg
    - College festival/event photo.

11. movie.jpg
    - Movie/cinema memory.

12. favourite_photo.jpg
    - Your favourite photo of the two of you or of her.

## Optional music

Put your MP3 inside `music/` and name it:

our_song.mp3

Browsers generally require a user click before audio can start, so the website has an "Our song" button.

## Run locally

Just double-click `index.html`, or open the folder in VS Code and use Live Server.

## GitHub Pages

Upload all files and folders to the repository. Keep the folder structure unchanged.

Then enable:
Repository → Settings → Pages → Deploy from branch → main → /(root)

## Editing the diary

All story text is directly inside `index.html`.
All visual styling and animations are in `style.css`.
Quiz logic, music and floating hearts are in `script.js`.

No backend or database is required.
